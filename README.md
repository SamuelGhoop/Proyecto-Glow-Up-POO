# Proyecto-Glow-Up-POO
Aplicación de consola en Java 17 (POO) para gestionar catálogo, carrito y compras de una tienda de cosméticos. Incluye registro/login, alta y listado de productos, checkout, y módulos adicionales (fábricas, registro y consejo) con roles y acceso restringido. Sin persistencia (datos en memoria).
